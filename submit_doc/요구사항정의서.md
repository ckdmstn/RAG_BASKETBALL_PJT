# 요구사항 정의서

## 1. 프로젝트 개요
- 주제: KBL(한국프로농구) 선수·팀 지식 서비스 (RAG 기반)
- 사용자가 선수나 팀을 고르고 질문하면, 선수 데이터(RAG 1)와 외부 문서(RAG 2: 위키백과, 팀 정보)에서 근거를 찾아 출처와 함께 답한다.

## 2. 도메인 선정 근거
| 조건 | 충족 내용 |
|---|---|
| 항목 수 | 선수 186명(10개 구단) + 팀 정보 10건 (약 100건 이상) |
| 출처·이용 조건 | 한국어 위키백과(CC BY-SA 4.0, 출처 표시 의무), 선수·팀 JSON(웹 검색이 가능한 AI가 나무위키·언론 기사 등을 참고해 정리, 기준일 2026-09~10, 항목마다 source_urls 보유, 개인 학습용). 값의 정확성보다 "문서에 적힌 대로 답하는 RAG" 연습이 목적이며 정답은 색인된 문서 기준 |
| 근거 없이는 틀리는 질문 (3개 이상) | ① "안양 정관장 레드부스터스의 홈구장은 어디야?" → RAG 없이 옛 이름 "안양실내체육관"이라고 단정(오답), RAG는 "안양 정관장 아레나" ② "박정웅 선수는 몇 년도 드래프트에서 몇 순위로 어느 팀에 지명됐어?" → RAG 없이는 모른다고 답함, RAG는 "2024 KBL 신인선수 드래프트 1라운드 1순위, 안양 정관장" ③ "자니 오브라이언트 선수의 현재 소속팀은?" → RAG 없이는 모름(최신 정보), RAG는 "고양 소노 스카이거너스". 같은 비교에서 이민서의 출신 대학, 서울 SK의 우승 횟수도 RAG 없이는 답하지 못했다. (`docs/rag_comparison.md`, 정답이 있는 5문항 중 RAG 없이 0/5, RAG 사용 5/5) |
| 위험 도메인 여부 | 아님 (의료·법률·금융처럼 판단이 위험한 도메인이 아님) → 면책 안내는 두지 않는다 |

## 5. 범위 밖(알려진 한계)
- 규정(외국인 선수 등록 수 등)처럼 색인하지 않은 자료의 질문은 "확인되지 않습니다"로 답한다.
- 위키 캐시는 검색어 문자열이 같을 때만 적중한다.
- 선수 찾기의 경력 키워드 검색은 코드 필터를 통과한 선수 중 가까운 10명만 살펴본다.
